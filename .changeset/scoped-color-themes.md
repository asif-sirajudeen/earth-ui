Add scoped color themes. Import `@asif-sirajudeen/earth-ui/themes/blue.css` or `themes/green.css` after the package stylesheet and set `data-theme` on `<html>`. In copy mode, install them with `shadcn add @earth-ui/theme-blue` or `@earth-ui/theme-green`. Themes work with dark mode and leave the default tokens unchanged.
