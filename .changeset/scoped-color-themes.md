Add scoped color themes: `blue`, `green` and `setmore`. Import `@asif-sirajudeen/earth-ui/themes/<name>.css` after the package stylesheet and set `data-theme` on `<html>`. In copy mode, install one with `shadcn add @earth-ui/theme-<name>`. Themes work with dark mode and leave the default tokens unchanged. `blue` and `green` change color tokens only. `setmore` also sets `--radius` to 0.5rem and adds component rules for pill buttons, the focus ring and dark-mode field fills.
