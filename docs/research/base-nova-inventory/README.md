# base-nova inventory data

Raw data and scripts behind `docs/research/base-nova-inventory.md`. `inventory.json` is the extracted per-item data; `scripts/` rebuilds it; `tailwind-probe/` holds the Tailwind CLI 4.3.4 probe inputs and outputs.

To re-run, make a work directory `<dir>` outside the repository with `raw/base-nova-registry.json` (from https://ui.shadcn.com/r/styles/base-nova/registry.json), `items/<name>.json` (from `https://ui.shadcn.com/r/styles/base-nova/<name>.json`, for every `registry:ui` item plus `index`, `style`, `utils`, `use-mobile` and `use-highlighted-code`), and `addall/` (a copy of this repository's `components.json`, `styles.css`, `tsconfig.json` and `package.json` after `npx shadcn@4.23.0 add --all -y -o` and `npx shadcn@4.23.0 add sonner -y -o`). Then run, in order: `python3 -I scripts/extract.py <dir>`, `python3 -I scripts/batch.py <dir>`, `python3 -I scripts/render.py <dir>` (prints the inventory table and asserts placement and ordering), `python3 -I scripts/exports.py <dir>` (export-name count and collisions), and `python3 -I scripts/tickets.py <dir>/inventory.json .scratch/earth-ui-phase-1b/issues` (rewrites the tickets and asserts that every planned item is in exactly one ticket and that no ticket ships before a component it imports). Copy `<dir>/inventory.json` back here. `scripts/rsc-probe.mjs` runs with `node --conditions=react-server` in a project that has `@base-ui/react` installed. If the npm cache under `~` is not writable, set `npm_config_cache` to a folder inside `<dir>`.
