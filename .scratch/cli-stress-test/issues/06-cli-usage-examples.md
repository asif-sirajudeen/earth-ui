## Agent Brief

**Summary:** `earth-ui examples <name>` (or an `examples` field in `docs`) returns the synced Examples for a component.

**Current behavior:**
Examples exist only in the docs site. The package `files` list is `["dist", "styles.css"]`, so the npm package does not ship them, and the CLI cannot show them.

Facts about the synced Examples:
- Most import from the package (for example `@asif-sirajudeen/earth-ui/button`), but many also import app-level packages: `lucide-react` (132 files) and `sonner` (20 files). A few (for example typography-large, shimmer-color) import nothing from the package.
- No Examples exist for `direction`, `sonner`, `use-highlighted-code`, `use-mobile`.
- No `-demo` Example exists for chart, code-block, direction, empty, message-scroller, sonner, trace.

**Desired behavior:**
The package ships the synced Examples (code only), and the CLI returns them per component, `-demo` first, as defined in `CONTEXT.md`. When there is no `-demo`, the remaining Examples are returned in name order.

**Why ready-for-human:** shipping Examples grows the package and needs owner decisions before work starts:
1. Which Examples ship (all, or `-demo` only).
2. A package size budget for the growth.
3. How Examples that import `lucide-react`, `sonner` or other app-level packages are handled (list the imports in the output, or exclude them).
4. New command or `docs` field.

**Key interfaces:**
- The Component Index (add an examples list per component).
- The package `files` list and the build step that would copy Examples into `dist`.

**Acceptance criteria:**
- [x] `earth-ui examples dialog` (or the chosen shape) returns `dialog-demo` first, with code that imports from the package.
- [x] A component with Examples but no `-demo` (for example `chart`) returns its Examples in name order.
- [x] Each returned Example lists the non-package modules it imports (or the owner's chosen handling is applied).
- [x] Every component with at least one file in `site/examples` returns at least one Example; a test checks this against the folder.
- [x] Packed size growth stays within the owner's budget.
- [x] The package smoke test runs the new command.

**Out of scope:**
- Writing new examples (rejected, see `.out-of-scope/authored-examples.md`).

## Resolution

Owner decisions:
- Ship all Examples.
- A new `earth-ui examples <name>` command.
- Each Example lists its non-package imports.
- Budget: 250 KB packed.

`scripts/build-examples.mts` writes `dist/examples.json` and maps each Example by filename prefix to the longest matching component name. 414 Examples across 62 components. 64 files with no matching registry item are dropped. The tarball grows by 86,824 bytes. `-demo` comes first, then the rest in name order. A component with no Examples gets `[]` plus a `note`. `package:smoke` runs `examples dialog`.
